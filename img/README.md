# Imagens Transportes75

## Estrutura

- `hero/`     → Imagem principal da homepage (1920x1080 ou maior)
- `logo/`     → Logomarca em PNG transparente + favicon
- `frota/`    → Fotos dos caminhões/cegonhas
- `servicos/` → Imagens ilustrativas dos serviços (cegonha, leilão, sinistrado, particular)
- `blog/`     → Imagens dos artigos do blog
- `equipe/`   → Foto do Sergio Torres e outros membros

## Nomes recomendados (otimizados para SEO)

### Hero
- `hero/transporte-veiculos-bahia-sao-paulo-cegonha-transportes75.webp`

### Logo
- `logo/logo-transportes75.png` (versão colorida, transparente)
- `logo/logo-transportes75-branco.png` (versão branca para fundos escuros)
- `logo/favicon.png` (32x32 ou 64x64)
- `logo/apple-touch-icon.png` (180x180)

### Equipe
- `equipe/sergio-torres-transportes75.webp`

## Formato recomendado

- **WebP** (melhor compressão, suportado por todos os navegadores modernos)
- **PNG** apenas para logos (precisa transparência)
- **JPG** alternativa para fotos

## Tamanho máximo

- Hero: até 500KB (otimizado)
- Logo: até 50KB
- Fotos: até 200KB cada
